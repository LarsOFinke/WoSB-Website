# Ammunition seed audit

Audit date: 2026-07-28

The selectable ammunition and tactical-payload catalog now contains 16 stable
seed entries. The two missing current broadside ammunition types were added:

- Heavy Shots (`heavy-shots`)
- Saxon Shots (`saxon-shots`)

Complete catalog:

- Bar Shots
- Burning Arrows
- Fire Ship
- Grapeshot
- Heated Shots
- Heavy Shots
- Large Phosphorous Mine
- Large Shrapnel Mines
- Phosphorous Shots
- Round Shots
- Saxon Shots
- Shrapnel Rounds
- Small Flaming Barrels
- Small Gunpowder Barrels
- Small Phosphorous Barrels
- Strike Rounds

No unverified damage, reload or penetration values were invented. The seed
records model selectable payload names only until quantified in-game tooltips
or reproducible measurements are available. Stable seed IDs allow later values
to be added without replacing existing database identities.

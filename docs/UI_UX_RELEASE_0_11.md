# RBV UI/UX release 0.11

## Iteration 1: identity and information architecture

- Replaced the long one-line title with a scalable RBV lockup: emblem, two-line name and descriptor.
- Reorganized navigation into public, member and staff groups.
- Added icon-supported labels while retaining text and tooltips for clarity.
- Standardized Profile, Fleet Portal, Fleet Command and Staff Panel around shared workspace headers,
  metrics, cards and action areas.
- Preserved public access to Fleet Portal, authentication and Builds while making protected modules
  visibly distinct.

## Iteration 2: interaction and responsive polish

- Added route-aware document titles, skip navigation and Escape-to-close mobile navigation.
- Improved focus states, hover feedback, empty states and reduced-motion behavior.
- Tuned the brand and top navigation across desktop, compact desktop, tablet and phone breakpoints.
- Reduced visual noise through consistent border, shadow, spacing and typography rules.
- Added responsive staff tabs, single-column profile/fleet layouts and balanced mobile actions.

The RBV monogram is intentionally the compact identity at narrow widths, while the full
“Royal Blackwater Vanguards” name remains available in the lockup and accessible label.

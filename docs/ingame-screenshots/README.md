# In-game screenshots

This directory contains the original in-game screenshots used to verify ship
statistics and ship-specific upgrade seed data. These files are reference
material, not project-licensed content.

The screenshots are intentionally versioned with the repository as source
evidence. Do not remove or optimize them without preserving the original files
and updating `SHA256SUMS.txt`. Do not publish, redistribute, or copy them into
a release or hosted asset directory while rights-holder permission is pending.

- Imported: 2026-07-28, 2026-07-29 and 2026-07-31
- Scope: 254 owned-ship statistics, upgrade, modification and reference screenshots covering 41 ships
- Integrity manifest: `SHA256SUMS.txt`
